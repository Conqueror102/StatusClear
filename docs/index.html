Before you install

Android will warn you.
That's normal.

StatusClear isn't on the Google Play Store yet, so Android doesn't recognise where it came from. It shows this exact warning for every app installed from a website, no matter what the app is. It's about the source, not about StatusClear. Here's what you'll see, step by step:

Swipe to see each step

It can't upload your files

StatusClear asks Android for no permissions at all, not even internet access. Check it yourself: Settings › Apps › StatusClear › Permissions.

Every line is public

The full source code is on GitHub. Anyone can read exactly what it does.

Signed by its developer

Every release is signed with the same key, so Android refuses a fake “update”. Fingerprint: ddaa7be5…46a1c16

Checked by Play Protect

Google Play Protect scans it during install. In our tests it installed with no flags.

On Samsung, Xiaomi and others the screens look a little different, but the steps are the same: allow your browser or file manager to install apps, then tap Install. Only ever download StatusClear from this page or its GitHub releases.
Questions

Good to know

Is it really free?

Yes. No ads, no subscription, no account. It's open source under the GPL-3.0 license.

Why isn't it on the Play Store?

Not yet. Until then you install it straight from this site, which is why Android shows the “unknown apps” warning. Every update is signed with the same key, so new versions install cleanly over the old one.

Which download do I need?

Almost every phone from the last 7+ years needs the standard version, which is what the green button downloads. If your phone says “App not installed”, try the 32-bit version for older phones. All versions are on the releases page.

Play Protect asked to scan the app. Is that a problem?

No. Some phones ask to scan apps that are new to Google. Tap “Scan app” and it will check StatusClear and let it install.

Does it work with WhatsApp Business?

Yes. If WhatsApp isn't installed but WhatsApp Business is, StatusClear shares straight to it.

My Status still looks soft. Why?

Don't trim, crop or add text inside WhatsApp after sharing: any edit makes WhatsApp re-encode it. For wide pictures, try “Fill screen” so the picture uses the whole Status screen.

Is there an iPhone version?

Not yet. StatusClear is Android only for now.
